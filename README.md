# Wings of Kasaragod

A static educational nature experience built with HTML5, CSS3 and vanilla JavaScript. No account or backend is required.

## Run locally

With Python 3 installed, run `python3 -m http.server 3000` from this directory, then open http://localhost:3000.

## Project

The site explores birdlife and nature destinations in Kasaragod, Kerala, with 22 sourced bird profiles and a language selector for English, Malayalam, Kannada and Tulu. The upgraded experience adds layered CSS 3D depth, pointer parallax, scroll movement, card tilt, and reduced-motion/mobile fallbacks.

See the downloadable project package for the complete image library, research notes, and bundled UI/UX Pro Max skill.
